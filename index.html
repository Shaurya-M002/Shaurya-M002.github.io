01 about

who i am

i'm shaurya. electrical engineering out of IIT delhi, now a data scientist at skan.ai. the title on the CV says "applied AI"; what i actually do most days is try to get models to reason a little better and run a lot cheaper.

right now that means leading a small team building a computer-use agent — the kind that drives a real desktop GUI, screenshot by screenshot, for finance workflows. a stateless step executor, set-of-mark prompting, a thinker/grounder split for visual grounding, and humans in the loop when it's unsure. before that i was doing process discovery: next-activity prediction with a hand-built transformer, fine-tuning qwen / flan-t5 / gemma, and multi-model RAG.

but the part i'd do for free is the low-level stuff: fused kernels, where memory actually goes during training, whether a reasoning trace has to be sequential at all. i'm not a "big model, more GPUs" person — i'm a "why is this wasting 5x the memory it needs" person. i also mess with lattice crypto for fun, which is a different way of caring about the same thing: making an idea small and exact.

03 projects

things i built to understand something

PaCT parallel continuous thought

a latent-reasoning framework that drops the recurrent unrolling in continuous thought via stage-wise parallel resynthesis — learnable query codebook + cross-attention. 4–9× faster training than coconut while matching or beating it on gsm8k / prontoqa / prosqa, scaled to llama-3b and 8b.

forge gpu kernels

custom triton kernels for memory-efficient training: fused linear + cross-entropy with tiled vocab (no full logit materialization), single-pass rmsnorm/layernorm, and fused swiglu + rope forward/backward. the thing that made unsloth feel like home.

hobitat a social app that didn't catch

a social network for slowly getting good at hobbies, in public. i got the shape wrong — built a consistency-shaped product for an inconsistency-shaped behaviour. open-sourced, app + web. the postmortem →

ds coin / FHE cryptography for fun

a toy cryptocurrency in java (authenticated linked lists, merkle trees), and a lattice build-up from SIS and regev's LWE all the way to a ring-LWE fully homomorphic encryption scheme.

also a paper: glaucoma abnormality classification using YOLO and SWIN transformer, IEEE ISBI 2024.
